# MLCalculator Windows 1.1.1

MLCalculator-1.1.1-Windows.exe를 실행하세요. Windows 10/11 64비트와 Microsoft Edge WebView2 Runtime이 필요하며 Python 설치는 필요 없습니다.

## 추가 기능

플레이어 스텟에서 `다이아 & 레전드`·`플&골&실`을 선택할 수 있고, 총공격력과 목표 레벨이 표시됩니다.
예상 모집 탭에서도 두 그룹을 별도로 선택할 수 있습니다. 영어 화면에는 `Dia & LL`·`P,G,S`로 표시됩니다.
언어, 테마, 기존 입력값과 새로운 입력값 및 리그 선택은 자동 저장됩니다.

## 계산식

장비 값은 300%일 때 300을 입력합니다.

- 다이아 공격력 = 병력 × (100 + 장비 공격력 + (레벨 − 1) × 4) ÷ 100
- 플레 공격력 = 병력 × (100 + 장비 공격력 + (레벨 − 1) × 2) ÷ 100
- 다이아 모집 = 부대 생산량 × (장비 모집 + (레벨 − 1) × 6) ÷ 100
- 플레 모집 = 부대 생산량 × (장비 모집 + (레벨 − 1) × 3) ÷ 100

모집에는 기본 100%를 별도로 더하지 않습니다. 모집 결과는 단위에 맞춰 소수점 한 자리까지 표시하며, 계산에는 반올림 전 값을 사용합니다.
병력 1G·장비 300%·레벨 105: 다이아 8.16G / 플레 6.08G.
생산량 3G·장비 모집 360%·레벨 110: 다이아 30.4G(정확히 30.42G) / 플레 20.6G(정확히 20.61G).

## 빌드

frontend 폴더에 수정 가능한 React/TypeScript 원본이 포함되어 있습니다.
Node.js 22.13 이상과 pnpm을 준비해 frontend에서 pnpm install 및 pnpm build를 실행하면 www가 생성됩니다.
Python 3.12 64비트 가상환경에서 pip install -r requirements.txt 후 build.ps1을 실행하면 dist/MLCalculator.exe가 생성됩니다.

## 실행 정보

계산과 화면은 인터넷 없이 작동합니다. 데이터는 %LOCALAPPDATA%\MLCalculator\WebView2에 저장됩니다.
로컬 포트 18743을 사용하며 한 번에 하나의 창을 실행합니다.
성 아이콘과 기존 9개 언어·다크/화이트 모드를 포함합니다. Windows 코드 서명 인증서는 적용하지 않았습니다.
